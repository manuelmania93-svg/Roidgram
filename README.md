# Roidgram

A full-featured messaging app for Android.

- Chats, groups, channels and calls
- Media sharing, stickers and saved messages
- Themes and customization
- On first launch you enter your own Telegram API credentials
  (created free at my.telegram.org) before the normal phone-number login
